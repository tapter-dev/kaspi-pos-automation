What is a cashier?

A cashier is a separate phone number with the “Cashier” role in Kaspi Pay. Kaspi sends an SMS code to it so the service can be linked.

Prepare the cashier’s phone before starting. The complete authorization window lasts about ten minutes.

Before linking, check 3 things

Tick each one to unlock the next step.

1

The number is added to Employees

Kaspi Pay → Settings → Employees → Add employee.

2

The role is “Cashier” only

Not Director, Accountant, Manager, or another role.

3

Don’t sign in under this number afterward

Signing in to Kaspi Pay with the cashier number can displace this connection.

Enter the cashier’s number

Kaspi will send an SMS code to this number.

What role does this number have in Kaspi Pay?

Select the same role configured in Kaspi Pay.

This number won’t work

In Kaspi Pay it must have only the “Cashier” role.

Show how to change it →

Important before the SMS

Don’t sign in to Kaspi Pay under this number

After connecting, signing in with this cashier number will end the automation session and payments will stop.

Enter the SMS code

The code expires quickly. Enter it as soon as it arrives.
