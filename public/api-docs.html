Developer reference

Kaspi Automation API v1

OpenAPI 3.1 YAML

Authentication

Create an API key in the customer dashboard and send Authorization: Bearer kpa_live_…. Keys are tenant-bound and support payments:read and payments:write scopes.

Create a QR payment

curl -X POST https://your-host/api/v1/payments \
  -H 'Authorization: Bearer kpa_live_…' \
  -H 'Idempotency-Key: order-1001-attempt-1' \
  -H 'Content-Type: application/json' \
  -d '{"method":"qr","amount":1250,"externalOrderId":"ORDER-1001"}'

Webhook verification

Compute hex HMAC-SHA256 over X-Webhook-Timestamp + "." + rawRequestBody using the endpoint signing secret. Reject stale timestamps and compare signatures in constant time. Return any 2xx response to acknowledge delivery.
